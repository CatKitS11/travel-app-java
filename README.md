## 🌟 Features

### Core Functionality
- **Trip Management**: Create, edit, and delete comprehensive trip itineraries with ease
- **Photo Gallery**: Upload and manage high-quality travel photos using Supabase Storage
- **Smart Search**: Find your next adventure with keyword-based trip searching
- **User Dashboard**: Personalized dashboard to manage your trips and profile
- **Authentication**: Secure JWT-based authentication powered by Clerk

### User Experience
- **Responsive Design**: Modern UI built with Tailwind CSS and Lucide Icons
- **Interactive Maps**: Visual location integration using Google Maps
- **Real-time Feedback**: Instant alerts and confirmation dialogs for user actions
- **Smooth Navigation**: Seamless client-side routing with Vue Router
- **Infinite Scroll/Pagination**: Efficient browsing of trip lists

### Technical Highlights
- **Secure File Uploads**: Integrated Supabase Storage for reliable media handling
- **Webhook Integration**: Real-time user synchronization via Clerk webhooks
- **Robust Backend**: Spring Boot REST API with strict validation and error handling
- **Type Safety**: Full TypeScript support on the frontend for reliable code

## 🛠️ Tech Stack

### Frontend
- **Framework**: Vue 3 (Composition API + Script Setup)
- **Build Tool**: Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide Vue
- **Routing**: Vue Router
- **HTTP Client**: Axios

### Backend & Database
- **Framework**: Spring Boot 3.5.7
- **Language**: Java 21
- **Database**: PostgreSQL
- **Security**: Spring Security + JWT
- **Build Tool**: Maven
- **ORM**: Spring Data JPA (Hibernate)
- **Deployment**: Google Cloud Run (Containerized Deployment)

### Services & Integrations
- **Authentication**: Clerk (Identity Management)
- **Storage**: Supabase Storage (Object Storage for Images)
- **Webhooks**: Event handling for third-party services
